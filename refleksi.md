Pada praktikum Pertemuan 7, saya mempelajari cara memindahkan project KursusKu dari PHP biasa ke framework Laravel. Perbedaan yang paling terasa adalah Laravel memiliki struktur file dan pembagian tugas yang lebih teratur sehingga kode lebih mudah dikelola. Bagian yang paling saya pahami adalah Blade View karena digunakan untuk menampilkan data kursus ke dalam halaman web, sedangkan hubungan antara Route dan Controller masih perlu saya pelajari lebih lanjut. Salah satu kendala yang saya alami adalah kesalahan saat berpindah direktori melalui terminal karena saya mencoba masuk ke folder yang sebenarnya tidak ada di dalam direktori project. Saya mengatasinya dengan memeriksa lokasi terminal dan memastikan bahwa perintah dijalankan dari folder project Laravel yang benar. Saya juga mempelajari cara memeriksa route menggunakan perintah `php artisan route:list` serta memahami bagaimana data kursus dikirim dari Controller ke Blade View. Melalui praktikum ini, saya memahami bahwa aplikasi Laravel tidak hanya harus tampil di browser, tetapi juga harus memiliki alur pemrosesan yang terstruktur dan dapat dijelaskan.
