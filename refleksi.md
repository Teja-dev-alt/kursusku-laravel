Pada praktikum pertemuan 7, saya mempelajari cara memindahkan project KursusKu dari PHP biasa ke framework Laravel. Perbedaan yang paling terasa adalah Laravel memiliki struktur file dan pembagian tanggung jawab yang lebih teratur. Route bertugas menentukan tujuan permintaan, Controller menyiapkan data, sedangkan Blade View menampilkan data kepada pengguna. Bagian yang cukup membingungkan adalah pengaturan terminal dan proses menjalankan aplikasi melalui Laravel serta Vite. Saya memeriksa masalah tersebut dengan memastikan terminal berada di folder project yang benar dan menjalankan perintah yang sesuai. Saya juga mempelajari cara memeriksa route menggunakan `php artisan route:list` dan menguji perubahan data kursus melalui Controller. Dari praktikum ini, saya memahami bahwa aplikasi yang tampil di browser perlu didukung oleh struktur kode yang benar dan dapat dijelaskan.
